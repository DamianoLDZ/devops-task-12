## System Health Check

A Python application for monitoring disk usage on Linux systems.

## Features

- Checks total disk capacity.
- Displays used disk space.
- Displays available disk space.
- Calculates disk usage percentage.

## Requirements

- Python 3.12 or newer.

## Usage

Run the application:

    python3 src/disk_check.py

## Tests

Run unit tests:

    python3 -m unittest discover -s tests -v

## Continuous Integration

GitHub Actions automatically runs unit tests after each push and pull request.
