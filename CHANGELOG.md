## [0.1.0] - 2026-11-12

### Added
- Initial project structure with `.gitignore` and Python source files.
- Disk usage monitoring functionality using the Python standard library.
- Unit tests for disk usage calculations.

- Project architecture documentation.

- Automated test execution through GitHub Actions.
